Мерило — «Оформление кода» в 00-project.md.
Сервер: голый except — BLOCKER; текст ошибки для пользователя с путём, SQL или трассировкой
— BLOCKER; «except Exception» без журнала и понятного ответа — MAJOR; логические флаги в
параметрах; магические числа; нет аннотаций в переписанных модулях (tests/code_style.json).
Интерфейс: var вне boot.js — BLOCKER; промис без обработки отказа, await без try/catch в
обработчике события — MAJOR; смешение then и async/await; == вместо ===; нет JSDoc у
открытого метода; цепочки if/else и вложенные ?: вместо таблиц соответствий.
Общее: функции длиннее 50 строк и вложенность глубже 3 — MAJOR; имена короче 3 знаков
(кроме разрешённых в 00-project.md), мёртвый и закомментированный код, неиспользуемые
импорты, функции и классы CSS — MINOR.
Безопасность и расчёты здесь НЕ проверяй.
