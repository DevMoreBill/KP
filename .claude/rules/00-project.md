# Проект «Конструктор КП ПНЕВМОТЕХ» — главнее общих правил ECC

Правила в `rules/ecc/` — общие практики из ECC (github.com/affaan-m/ECC, v2.2.3). При расхождении действует этот файл
и сложившийся стиль кода проекта.

## Стек и ограничения
- Сервер: Python 3, **только стандартная библиотека** (`app/*.py`, `http.server`, SQLite через `sqlite3`). Не добавлять
  зависимости из PyPI/npm без явной просьбы — программа собирается в один EXE (PyInstaller, `kp.spec`,
  `.github/workflows/build-exe.yml`). Новый модуль сервера — добавить в `hiddenimports` в `kp.spec`.
- Клиент: обычный JavaScript без сборщика и фреймворков (`app/web/js/**`, глобальные функции, `'use strict'`),
  CSS — `app/web/css/*.css`, подключение — `app/web/index.html`. Правила ECC про React/TSX/компоненты не применяются.
- Интерфейс, сообщения, комментарии, журнал изменений, коммиты — **на русском**.

## Стиль: как в окружающем коде
- Не переписывать существующий код под ECC-правила «неизменяемые данные», «аннотации типов везде», «файлы ≤ 400 строк»:
  состояние КП (`S`, `S.deal`) намеренно изменяемое, аннотаций типов в проекте нет. В новом коде — по месту, как рядом.
- Формат коммитов — как в истории репозитория (`3.x.y: что сделано` + список), а не `feat:/fix:`.

## База данных
- Схема меняется только миграциями в `app/storage.py` (атомарно, `MIGRATION_FILL`), без ручной правки рабочей базы
  пользователя. Совместная правка — номер ревизии (`rev`, заголовок `X-KP-Rev`, ответ 409).

## Проверки перед коммитом
- `python3 -m pyflakes app/*.py`, ESLint для `app/web/js`, сценарии Playwright на копии базы (не на рабочей).
- Версия: `app/version.py` + `APP_VERSION` и журнал в `app/web/js/features/help.js`, README.
- Ключи API и пароли — никогда в репозиторий.
