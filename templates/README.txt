ШАБЛОНЫ КОММЕРЧЕСКИХ ПРЕДЛОЖЕНИЙ

Каждая папка здесь — отдельный шаблон КП. Шаблон выбирается в программе: раздел «Титульный лист» → «Шаблон КП».
По умолчанию используется «pnevmotekh» (ПНЕВМОТЕХ).

Состав папки шаблона:
  template.json  — название шаблона, цвета (HEX без #), тексты «О компании», три преимущества,
                   список «Нам доверяют», сайт в подвале, начало имени файла (filePrefix).
                   Открывается Блокнотом; сохраняйте в кодировке UTF-8.
  base.docx      — основа оформления: шапка страницы (логотип, реквизиты), поля, размер листа, стили.
                   Правится в Word: двойной щелчок по верхнему колонтитулу → изменить → сохранить.
                   Текст страницы и нижний колонтитул программа заменяет содержимым КП.
  clients.jpg    — страница «Наши клиенты» (необязательно; уберите "clientsImage" из template.json,
                   чтобы страницы не было).

Как подключить новый шаблон (например, для другой компании группы):
  1. Скопируйте папку pnevmotekh и назовите копию латиницей, например: partner
  2. В base.docx замените шапку (логотип, реквизиты).
  3. В template.json поменяйте name, filePrefix, цвета, тексты.
  4. Перезапустите программу или откройте раздел «Титульный лист» — шаблон появится в списке.

При работе всем отделом шаблоны лежат на компьютере-сервере отдела, в этой папке, — они общие для всех.
