# Образцы данных

| Файл | Что это |
|---|---|
| `kp.sqlite3` | действующая база программы (каталог 744 позиции, журнал КП, клиенты, свои типы). Ключи API Checko и DaData **удалены** — укажите их заново в программе («Интеграции»). Картинки каталога в базу не входят: они лежат в `data/img` рядом с программой. |
| `catalog_example.json` | три позиции каталога (ДГУ, винтовой компрессор, чиллер) в формате «Каталог → Загрузить» — образец для подготовки новых данных |
| `user_types.json` | собственные типы оборудования из базы (например, «Чиллеры») — дополняют `app/equipment_types.json` |

Чтобы работать с этой базой: положите `kp.sqlite3` в папку `data` рядом с «Конструктор КП.exe» (при закрытой программе).
