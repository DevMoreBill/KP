# Промт: пополнение каталога оборудования

Комплект для подготовки новых позиций каталога нейросетью по документам производителя.

| Файл | Зачем |
|---|---|
| `Промт.txt` | сам промт — вставить в чат целиком |
| `приложить к промту/catalog_example.json` | три реальные позиции из базы (ДГУ, винтовой компрессор, чиллер) — образец структуры и стиля |
| `приложить к промту/equipment_types.json` | встроенные типы оборудования: ключи фильтров, группы, слоты галереи |
| `приложить к промту/user_types.json` | свои типы из базы (например, «Чиллеры») |

## Как пользоваться

1. Вставьте в чат текст из `Промт.txt`.
2. Приложите три файла из папки `приложить к промту`.
3. Приложите документы производителя (PDF, DOCX, XLSX) и папки с картинками — имя картинки = название модели.
4. Получите `catalog_<производитель>.json` и `report.txt`. Прочитайте отчёт: позиции без фото, сомнительные вырезки, противоречия.
5. В программе: «Каталог» → «Загрузить» → выберите полученный файл. Картинки сохранятся сами; позиции с тем же id обновятся с сохранением цен и истории.

Если в программе появятся новые типы оборудования или поля, обновите файлы в `приложить к промту`:
`equipment_types.json` — из `app/`, `user_types.json` и `catalog_example.json` — выгрузкой из действующей базы (см. `samples/`).
