# Промт: создание и пополнение каталога оборудования

Комплект для подготовки позиций каталога нейросетью по документам производителя. Итог — **один файл** `.json`
со всеми позициями, картинками (внутри файла) и, если нужно, новыми категориями оборудования.

| Файл | Зачем |
|---|---|
| `Промт.txt` | сам промт — вставить в чат целиком |
| `приложить к промту/catalog_example.json` | реальные позиции из базы — образец структуры и стиля |
| `приложить к промту/equipment_types.json` | встроенные категории: параметры, фильтры, группы, слоты галереи |
| `приложить к промту/user_types.json` | свои категории отдела (например, «Чиллеры») |

## Как пользоваться

1. Вставьте в чат текст из `Промт.txt`.
2. Приложите три файла из папки `приложить к промту`.
3. Приложите документы производителя (PDF, DOCX, XLSX) и папки с картинками — имя картинки = название модели.
4. Получите файл `catalog_<дата>.json` и отчёт в чате. Прочитайте отчёт: позиции без фото, сомнительные вырезки, противоречия, новые категории.
5. В программе: «Каталог» → «Ещё» → «Загрузить файл каталога (.json)». Новые категории добавятся сами (с их параметрами
   и фильтрами), картинки разложатся по папкам категорий, позиции с тем же id обновятся с сохранением цен и истории.

Если в программе появятся новые категории или поля, обновите файлы в `приложить к промту`:
`equipment_types.json` — из `app/`, `user_types.json` и `catalog_example.json` — выгрузкой из действующей базы.
