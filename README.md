# Конструктор КП ПНЕВМОТЕХ

Программа для составления технико-коммерческих предложений (DOCX): каталог оборудования, расчёт цен,
журнал КП, контрагенты, шаблоны оформления. Собирается в **один EXE** — на компьютерах Python не нужен.
Работает на одном компьютере или как **сервер отдела** (одна база на всех, сотрудники — в браузере).

Инструкция для пользователей — [Инструкция.txt](Инструкция.txt), для администратора сервера отдела —
[server-setup/Как устроен сервер отдела.txt](server-setup/Как%20устроен%20сервер%20отдела.txt).

## Где взять EXE

GitHub → **Actions** → последний запуск «Сборка EXE для Windows» → **Artifacts**: EXE и архив «EXE + server-setup + Инструкция».

| Файл | Windows |
|---|---|
| `Конструктор КП` | 8.1 / 10 / 11, 64-бит (Python 3.12) |
| `Конструктор КП (Windows 7, 32-бит)` | 7 SP1 и новее, 32/64-бит (Python 3.8) |

Каждая сборка проверяется на Windows: запуск, база SQLite, каталог, шаблоны, типы, новый номер КП, сохранение DOCX, выход.
Релиз с файлами — тег `v*`: `git tag v1.0.0 && git push origin v1.0.0`.

## Состав

```
app/kp_server.py          HTTP-сервер (стандартная библиотека Python): API, выдача интерфейса, сборка на Windows
app/storage.py            база данных SQLite (data/kp.sqlite3)
app/counterparty.py       контрагенты: реквизиты по ИНН (Checko / DaData / ФНС ЕГРЮЛ), проверка Checko
app/app.html              интерфейс (JSZip, генератор DOCX и шрифт встроены — интернет не нужен)
app/equipment_types.json  справочник типов оборудования
app/icon.ico              значок
templates/                шаблоны КП (base.docx + template.json + clients.jpg), правятся вручную
seed/data/                стартовый каталог (654 позиции) и фото — загружаются в базу при первом запуске
server-setup/             установка сервера отдела, остановка, резервная копия
kp.spec                   настройки PyInstaller
.github/workflows/        сборка и проверка EXE
```

## Данные

| Где | Что |
|---|---|
| `data/kp.sqlite3` | каталог, журнал КП и нумерация, контрагенты, проверки Checko, ключи API, свои типы оборудования |
| `data/img/` | фото и логотипы (имя файла = хеш содержимого, повторы не хранятся) |
| `Коммерческие предложения/<Фамилия>/` | готовые КП `.docx` |
| `templates/` | шаблоны КП |
| `settings.json` | `mode` (`local` / `server`), `port` (17845), `dataDir` (папка данных на **локальном** диске), `docsShare` (сетевой путь к папке КП для сотрудников) |

Резервная копия — `server-setup/3. Резервная копия базы.bat` (согласованная копия базы «на ходу» + фото).
Переход с прежних версий (данные в JSON-файлах `data/catalog`, `data/kp`…) — автоматически при первом запуске;
старые папки остаются нетронутыми как резервная копия. Базу нельзя класть в общую сетевую папку — для работы отделом
используется сервер отдела.

## Сервер отдела

На постоянно включённом компьютере: `server-setup/1. Установить сервер отдела.bat` (от имени администратора) —
режим сервера, порт в брандмауэре, общая папка `\\ИМЯ\КП` (чтение), автозапуск при включении, ярлык `.url` для сотрудников.
Сотрудники открывают `http://ИМЯ-КОМПЬЮТЕРА:17845/`. Общие: каталог, журнал, нумерация, контрагенты, шаблоны, типы, ключи API.
У каждого в браузере: черновик, контакты менеджера, выбранный шаблон. По сети КП скачивается («Скачать .docx»),
«Путь к файлу» копирует сетевой путь. Выключается сервер только на самом сервере.

## Возможности

- **Клиент:** реквизиты по ИНН, справочник контрагентов (объекты, контактные лица), проверка Checko (в КП не выводится).
- **Оборудование:** быстрый поиск по каталогу, плитки видов оборудования, карточка позиции с вкладками
  (основное, описание и фото, характеристики, опции, автозаполнение через Claude), фото к блокам описания,
  схемы и чертежи, дублирование позиций. Каталог: фильтры по параметрам типа, импорт из Excel по шаблону.
- **Цены:** валюта КП, курсы ЦБ РФ (cbr.ru, резерв — cbr-xml-daily.ru), у каждой позиции закупка → маржа или наценка → цена.
- **Титул:** одна или несколько моделей, получатель, объект, дата; выбор шаблона КП.
- **Типы оборудования:** `app/equipment_types.json` + свои типы (кнопка «Типы оборудования»): параметры, фильтры,
  ключевые параметры титула, быстрые опции, кнопки изображений — без правки кода.
- **Вёрстка DOCX:** раздел характеристик не отрывается (первые ~7 см — вместе с заголовком), акцентные подзаголовки групп,
  неразрывные блоки «узел + фото», без пустого последнего листа. Имя файла: `<номер>_<префикс шаблона>_<клиент>_<оборудование>_<дата>.docx`.

## API (для справки)

`/api/ping`, `/api/catalog` (облегчённый список; `?full=1` — полный), `/api/catalog/{id}`, `/api/img`, `/img/{файл}`,
`/api/history`, `/api/kp/new`, `/api/kp/{id}/state|meta|docx|open|folder`, `/api/types`, `/api/templates`, `/tpl/{id}/{файл}`,
`/api/party?inn=`, `/api/check?inn=`, `/api/integrations`, `/api/clients`, `/api/cbr`, `/api/backup`, `/api/folder`, `/api/shutdown`.

## Запуск из исходников (для разработки)

`python app/kp_server.py` — данные создаются в `app/`.
