# Конструктор КП ПНЕВМОТЕХ

Программа для составления технико-коммерческих предложений (DOCX). Переписана с PowerShell
(`server.ps1` + ps2exe) на Python и собирается в **один EXE**, который запускается на любом
компьютере с Windows без установки Python, PowerShell-модулей и доступа в интернет.

Инструкция для пользователей — [Инструкция.txt](Инструкция.txt).

## Где взять EXE

GitHub → вкладка **Actions** → последний запуск «Сборка EXE для Windows» → блок **Artifacts**:

| Файл | Для каких Windows |
|---|---|
| `Конструктор КП.exe` | 8.1 / 10 / 11, 64-бит (Python 3.12) |
| `Конструктор КП (Windows 7, 32-бит).exe` | 7 SP1 и новее, 32- и 64-бит (Python 3.8) |

Перед публикацией каждый EXE проходит автоматическую проверку на Windows: запуск, каталог,
выдача нового номера КП, сохранение DOCX, выход.
Для релиза с файлами поставьте тег: `git tag v1.0.0 && git push origin v1.0.0`.

## Состав

```
app/kp_server.py     локальный HTTP-сервер (только стандартная библиотека Python) — замена server.ps1
app/app.html         интерфейс (с JSZip и встроенным шрифтом Onest — без обращений в интернет)
app/equipment_types.json  справочник типов оборудования (ДГУ, компрессоры, насосы, сварочные генераторы…)
app/icon.ico         значок программы
seed/data/           стартовый каталог (654 позиции: Tide Power, HERTZ, Energo, ТСС) и фото — раскладываются при первом запуске,
                     если рядом с EXE ещё нет data/catalog
kp.spec              настройки PyInstaller (один файл, без консоли, значок, сведения о версии)
Собрать EXE.bat      локальная сборка на Windows (нужен Python 3.8+)
.github/workflows/   сборка и проверка EXE на Windows в GitHub Actions
```

API, порт (`17845`), структура папок (`data/`, `Коммерческие предложения/`) и `settings.json`
совпадают со старой версией, поэтому EXE можно положить в прежнюю папку — данные подхватятся.

## Запуск из исходников

```
python app/kp_server.py
```

(данные создаются рядом со скриптом, в `app/`).

## Типы оборудования (масштабирование)

Конструктор не привязан к ДГУ: всё, что зависит от вида оборудования, описано в справочнике типов
`app/equipment_types.json`. Встроены типы:

| Группа | Типы |
|---|---|
| Генераторы | Дизель-генераторные установки, осветительные мачты, сварочные генераторы |
| Компрессоры | Винтовые, поршневые, центробежные |
| Насосы | Насосы и мотопомпы |
| Комплектующие / прочее | Шкафы АВР, прочее оборудование |

Тип задаёт:

- **fields** — параметры оборудования. Флаги: `num` — число, `range` — фильтр «от–до» в каталоге (+ быстрые
  кнопки `chips`), `facet` — фильтр-список, `values` — варианты для выбора, `kpi` — ключевой параметр
  (титул КП, карточка в каталоге, строка под названием), `group` — группа в таблице технических характеристик;
- **main** — основной параметр для сортировки (мощность, производительность, подача, сварочный ток…);
- **options** — быстрые кнопки опций и услуг для позиций этого типа;
- **coverTitle**, **item** — заголовок титула и название единицы;
- **match** — слова для автоопределения типа старых позиций по наименованию;
- **role** — `equipment` (основное оборудование, попадает на титул) или `accessory` (комплектующие).

### Как добавить новый тип

1. **Из программы:** кнопка «Типы оборудования» → «+ Новый тип» → поправить образец → «Сохранить тип».
2. **Файлом:** положить рядом с данными `data/types.json` в том же формате, что `equipment_types.json`.
   Типы с тем же `id` заменяют встроенные, новые добавляются, `"hidden": true` скрывает тип.
   При общей сетевой папке (`settings.json` → `dataDir`) справочник общий для всего отдела.

Код менять не нужно: фильтры каталога, форма параметров позиции, шаблон импорта из Excel, запрос для
автозаполнения через Claude и титул КП строятся по справочнику.

### Массовое наполнение каталога

«Подобрать из каталога» → «Импорт из Excel» → выбрать тип → «Скачать шаблон для Excel» → заполнить →
вставить таблицу (или выбрать CSV) → «Импортировать». Закупочная цена и валюта из таблицы сразу
участвуют в расчёте цены по марже. Повторный импорт той же модели обновляет позицию, фото и история цен сохраняются.

### API

`GET /api/types` — справочник (встроенный + `data/types.json`), `PUT /api/types` — сохранить свои типы
(`{"types": [...]}`).

## Дополнительные изображения (узлы, контроллер, схемы)

В карточке позиции («Фото, описание и характеристики») — блок «Дополнительные изображения». Быстрые кнопки
зависят от типа оборудования (`gallerySlots` в справочнике): у ДГУ — альтернатор, контроллер, двигатель,
габаритный чертёж, электрическая схема; у винтового компрессора — винтовой блок, контроллер, принципиальная схема и т. д.
Файлы можно перетащить в блок или вставить из буфера (Ctrl+V); PNG (схемы, чертежи) сохраняются без потери чёткости.
Для каждого изображения — подпись, ширина (авто / половина / вся ширина), флажок «в КП» и порядок.
Изображения сохраняются в каталог вместе с позицией.

Вёрстка в Word: после технических характеристик — раздел «Узлы, фото и схемы»: фото по два в ряд, схемы и чертежи
на всю ширину. Каждый ряд неразрывный и переносится на следующую страницу целиком, заголовок не отрывается от первого ряда,
поэтому пустое место в конце страницы не больше высоты одного ряда. Длинная таблица характеристик в две колонки
теперь одна «плоская» таблица — она переносится построчно, без пустых мест.
