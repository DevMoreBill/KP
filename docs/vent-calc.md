# Вентиляция станции: расчёт притока и выброса горячего воздуха

Расчёт — класс `VentCalc` (`app/web/js/features/station-systems.js`), вызывается из расчёта тепла станции
(`StationHeat.calc`, `features/layout/station-heat.js`); размеры и места жалюзи — `StationVent.calc`; расчётная записка — `VentSizing`
(`station-calc.js`). Все коэффициенты — в файле инженерных правил `app/web/rules/stations.json` (группа «Тепло и
вентиляция», правила `vent.*` и `air.cp`) с источниками и статусом; их можно править в «Настройки → Инженерные правила
станций» (новая версия правил, прежняя остаётся для отката). Единицы — СИ: кВт, м³/ч, м², м/с, °C, Па.

## Что вводит менеджер и откуда берутся данные

| Данные | Откуда |
|---|---|
| Мощность компрессора N, кВт; тип (винтовой, поршневой, центробежный, спиральный) | состав станции (карточка оборудования; тип — по названию и характеристикам) |
| Тепловыделение по паспорту, кВт; воздух охлаждения по паспорту, м³/ч | строки характеристик карточки («Тепловыделение», «Расход охлаждающего воздуха») — **важнее формулы** |
| t_нар летом / зимой | ТЗ заказчика или «Условия для расчёта станции» (по умолчанию: лето +35 °C, зима — по климату) |
| t_вн летом (допустимая в помещении) | 40 °C (`vent.temps.tIn`), «эксперт» — своё |
| t_вн_мин зимой | +5 °C (как в расчёте отопления) |
| Размеры помещения | контейнер станции (внутренние, без отсека бака ДГУ) |
| U ограждений | по утеплителю контейнера (как в расчёте отопления); неутеплённый — «эксперт» 1,5…2,5 |
| Рекуператор | система «Рекуператор (по требованию)» в «Системах контейнера» (по требованию заказчика), тип и КПД — «эксперт» |

**Режим «эксперт»** — «Подбор станции → Условия для расчёта станции → Вентиляция и отопление — режим «эксперт»»: k,
нагрев воздуха в компрессоре, t_вн, Δt, скорости притока и выброса, запас притока, U, вытяжной вентилятор, тип и КПД рекуператора, температура и
влажность выбросного воздуха, отопительный период. Пустое поле — значение из правил. Значение вне допустимого диапазона
не принимается (предупреждение, расчёт по умолчанию).

> **Важно.** Сильнее всего на результат влияют **k** (доля мощности, уходящая в тепло) и **U** (теплопередача
> ограждений). k = 0,9 вместо 0,7 — расход воздуха больше на 29 %; U неутеплённого контейнера (2,0) больше утеплённого
> (0,48) в 4 раза — во столько же раз больше потери зимой. Тепловыделение по паспорту компрессора точнее любого k.

## Формулы

**Лето** — сбалансированная схема по умолчанию (решение ПНЕВМОТЕХ 12.10): горячий воздух компрессора уходит
воздуховодом наружу, компрессор протягивает воздух через помещение, проёмы — по рекомендациям Atlas Copco.
1. Тепло компрессора: Q = N·k (паспорт — важнее). k по умолчанию 0,9; допустимо: винтовой 0,65…1,0, поршневой
   0,70…0,95, центробежный 0,60…0,90.
2. Плотность воздуха: ρ = 353 / (273 + t_нар), кг/м³ (101 325 Па / (287,05·T)).
3. Воздух охлаждения — собственный вентилятор компрессора: L_охл = Q·3600 / (c·ρ·Δt_к), c = 1,005 кДж/(кг·°C),
   Δt_к — нагрев воздуха в компрессоре, 15 °C (`heat.cool_dt`; пример паспорта 75 кВт — 11 700 м³/ч, это ≈ 18 °C).
   Паспортный расход — важнее.
4. Перепад помещения: Δt = t_вн − t_нар (меньше 5 °C — предупреждение, расчёт при 5 °C) — только для тепла корпусов,
   осушителей и солнца: L_пом = Q_пом·3600 / (c·ρ·Δt).
5. Приток — **один поток**: L_приток = max(L_охл, L_пом) + воздух на сжатие (компрессор протягивает воздух через
   помещение, отдельная вентиляция при работе не нужна). Воздух у входа компрессора t = t_нар + Q_пом·3600 / (c·ρ·L) —
   не выше t_вн (Atlas Copco допускает до 46 °C).
6. Кратность: не меньше 3V (недостающее — общеобменной вентиляцией), аварийная — 8V (справочно).
7. Остановленные компрессоры — вытяжной вентилятор с термостатом: L = max(солнце, 3V)·1,15, не меньше 500 м³/ч;
   P = L·ΔP / (3600·1000·η), ΔP = 30 Па, η = 0,5. Решётка — вверху на стене выброса.
8. Проёмы по рамке: приток S = L_приток / (3600·3)·1,1 (запас 10 %), выброс S = (L_охл + L_вент) / (3600·4); у решётки
   не более 5 м/с (Atlas Copco). Воздуховод компрессора с жалюзи — не более 10 Па (штатный вентилятор; подтвердить по
   паспорту). Скорость в живом сечении решётки — справочно.
9. Система «Вентилятор в воздуховоде выброса» (компактно): приток 4 м/с, выброс 6 м/с; канальный вентилятор на
   L_охл, напор 100 Па, η 0,5.
10. Станции без компрессоров (насосные): естественная тяга общей вытяжки ΔP = (ρ_нар − ρ_вн)·g·h; меньше 5 Па —
    вытяжной вентилятор L·1,15, напор не менее 30 Па.

**Зима** (основной вариант — рециркуляция: горячий воздух компрессора возвращается в помещение клапаном)
11. Потери ограждений: Q_огр = U·A·Δt, Δt = t_вн_мин − t_нар_зима.
12. Минимальный воздухообмен: L_зима = max(2V, воздух на сжатие); его подогрев Q_вент = L·c·ρ·Δt / 3600.
13. Баланс: Q_баланс = Q_тепл (работающий агрегат) − (Q_огр + Q_вент); меньше нуля — подогрев (конвекторы).
14. Жалюзи зимой: доля открытия = L_зима / L_лето, не меньше 20 % (наименьшее открытие клапана).

**Рекуператор** (отдельная опция «по требованию заказчика»)
15. Целесообразен, если потери > 0,3·Q_тепл, или нужен подогрев, или требует заказчик.
16. Тип и КПД: пластинчатый 0,50…0,65, роторный 0,70…0,85, с промежуточным теплоносителем 0,45…0,60 (по умолчанию —
    он: приток и выброс на разных стенах).
17. t_после = t_нар + η·(t_выб − t_нар); ниже 0 °C при влажности выбросного воздуха > 60 % — обмерзание: предподогрев
    до +5 °C, ниже −15 °C — байпас, у пластинчатого — разморозка.
18. Экономия: Q_рекуп = L·ρ·c·η·Δt / 3600; за год — при средней температуре отопительного периода × сутки × 24 ч
    (по умолчанию — Москва, СП 131.13330: 205 сут, −2,2 °C).

Округление: площадь — до 0,01 м², расход — до 10 м³/ч, температура — до 0,1 °C. CFM = м³/ч / 1,699.

## Где видно результат

«Подбор станции → Компоновка» (строки «Вентиляция летом», «Вентиляция зимой», «Рекуператор»), раздел «Вентиляция и
отопление» расчётной записки (окно «Расчёт станции» и приложение к КП), ТЗ на сборку контейнера (жалюзи, скорости по
рамке, открытие зимой), габаритный чертёж и 3D (жалюзи и колпаки).

## Предупреждения

| Текст (начало) | Когда | Что делать |
|---|---|---|
| «Недостаточный перепад температур летом…» | t_вн − t_нар < 5 °C | расход посчитан при 5 °C; уточнить допустимую t в помещении по паспорту, принудительная вентиляция / охлаждение притока |
| «Скорость воздуха в притоке/выбросе … больше 5 м/с» | «эксперт»: скорость > 5 м/с | увеличить проём или включить «Вентилятор в воздуховоде выброса» |
| «Скорость … вне рекомендуемого диапазона» | приток вне 2…4, выброс вне 3…5 м/с | справочно |
| «Режим «эксперт»: … вне допустимого…» | число вне диапазона | взято значение по умолчанию |
| «Расход увеличен до нормативного минимума по кратности…» | расход меньше 3V | справочно |
| «Воздух у входа компрессора около … выше допустимых» | мал приток при большом тепле помещения | увеличить приток, проверить паспорт |
| «Естественная тяга общей вытяжки … меньше 5 Па» | станция без компрессоров, тяга мала | вытяжной вентилятор помещения (расход, напор, мощность — в тексте) |
| «Вытяжной вентилятор … меньше нужного (при остановленных компрессорах)» | «эксперт»: свой вентилятор мал | заменить вентилятор |
| «Зимой при работе тепла не хватает: дефицит …» | баланс < 0 | конвекторы и рециркуляция (рассчитываются автоматически) |
| «Рекуператор: приток после него … риск обмерзания» | t_после < 0 °C и влажность > 60 % | предподогрев, байпас, разморозка |
| «Не поместилось приточных жалюзи…» / «…колпаков выброса на крыше…» | проёмы не встали на стены и крышу | больший контейнер, воздуховод, другая компоновка (текст подсказывает) |

## Пример: винтовой компрессор 75 кВт в 20-футовом контейнере

Исходные: N = 75 кВт, k = 0,9, лето t_нар = +30 °C, t_вн = +40 °C; зима t_нар = −25 °C, t_вн_мин = +5 °C; контейнер
6,06 × 2,44 × 2,59 м, утеплитель 100 мм. Проверяется тестом `tests/js/station_calc.js` («пример — винтовой 75 кВт»).

| Шаг | Расчёт | Значение |
|---|---|---|
| Объём V | 6,06 · 2,44 · 2,59 | 38,30 м³ |
| Площадь ограждений A | 2·(6,06·2,44 + 6,06·2,59 + 2,44·2,59) | 73,60 м² |
| Тепло Q | 75 · 0,9 | 67,5 кВт |
| Δt помещения | 40 − 30 | 10,0 °C (тепла помещения в примере нет) |
| ρ при +30 °C | 353 / 303 | 1,165 кг/м³ |
| Воздух охлаждения L | 67,5 · 3600 / (1,005 · 1,165 · 15) = 13 836 | **13 840 м³/ч** (8 146 CFM) |
| L_мин = 3V / L_авар = 8V | 114,9 / 306,4 | 110 / 310 м³/ч (расход охлаждения больше) |
| Вентилятор стоянки | max(3V · 1,15 = 132, 500) | 500 м³/ч |
| Приток по рамке | 13 840 / (3600 · 3) · 1,1 | **1,41 м²** |
| Выброс по рамке | (13 840 + 500) / (3600 · 4) | **1,00 м²** |
| U по утеплителю | 1,15 / (0,17 + 0,1 / 0,045) | 0,481 Вт/(м²·°C) |
| Δt зима | 5 − (−25) | 30,0 °C |
| Q_огр | 0,481 · 73,6 · 30 | 1,06 кВт |
| L_зима | max(2V = 76,6) | 80 м³/ч |
| Q_вент | 80 · 1,005 · (353/248) · 30 / 3600 | 0,95 кВт |
| Потери / баланс | 1,06 + 0,95 = 2,02; 67,5 − 2,02 | избыток 65,48 кВт — подогрев не нужен, рециркуляция |
| Жалюзи зимой | 80 / 13 840 = 0,6 % → не меньше 20 % | открыты на 20 % |
| Рекуператор | 2,02 < 0,3 · 67,5 = 20,25 кВт | по расчёту не нужен |
| … если требует заказчик | с промежуточным теплоносителем, η = 0,5: t_после = −25 + 0,5 · 30 | −10,0 °C; ниже −15 °C — байпас и предподогрев до +5 °C |
| Q_рекуп при −25 °C | 80 · 1,005 · 1,423 · 15 / 3600 | 0,48 кВт |
| За год | при −2,2 °C: 0,105 кВт × 205 сут × 24 ч | 516 кВт·ч |

Вывод: летом компрессору нужно около 13 840 м³/ч воздуха — проём притока не менее 1,41 м² по рамке (одна жалюзи
1 500 × 950 мм), выброса — 1,00 м² (воздуховод компрессора с клапаном рециркуляции к жалюзи над ним). Зимой тепла
компрессора с запасом хватает — жалюзи прикрыты до 20 %, рециркуляция; рекуператор окупается слабо (около 516 кВт·ч в год).
