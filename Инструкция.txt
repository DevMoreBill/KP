КОНСТРУКТОР КП ПНЕВМОТЕХ

ЗАПУСК
Дважды щёлкните «Конструктор КП.exe». Откроется браузер с программой.
Устанавливать ничего не нужно: Python, PowerShell-скрипты и интернет не требуются —
всё (интерфейс, шрифт, стартовый каталог с фотографиями) уже внутри EXE.
Выход — кнопка «Выход» в правом верхнем углу программы.
Если программа уже запущена, повторный запуск EXE просто откроет её в браузере.
Лучше всего работает в Microsoft Edge или Google Chrome.

Какой EXE выбрать:
 • «Конструктор КП.exe» — Windows 8.1 / 10 / 11 (64-бит). Подходит почти всем.
 • «Конструктор КП (Windows 7, 32-бит).exe» — для старых компьютеров: Windows 7 SP1 и новее,
   32- и 64-битные.

КУДА ПОЛОЖИТЬ EXE
Положите EXE в отдельную папку, где у вас есть права на запись (например, «Документы\Конструктор КП»).
При первом запуске рядом с ним появятся:
Коммерческие предложения\   — готовые файлы .docx (имя начинается с номера КП)
data\catalog\               — каталог позиций (пополняется при каждом сохранении КП)
data\img\                   — фото и логотипы
data\kp\<номер>\            — данные каждого КП для журнала (можно открыть и отредактировать)
settings.json               — настройки (общая папка для отдела, см. ниже)
Резервная копия — просто скопируйте папку целиком.
Не запускайте EXE прямо из ZIP-архива — сначала распакуйте, иначе данные окажутся во временной папке.

ПЕРЕХОД СО СТАРОЙ ВЕРСИИ (server.ps1 / .bat)
Положите новый EXE в старую папку программы — он подхватит существующие data\ и
«Коммерческие предложения\», журнал и нумерация продолжатся. Старые server.ps1, *.bat,
make-exe.ps1 и app.html больше не нужны (их можно удалить).
Черновик в браузере тоже сохранится: адрес программы прежний — http://localhost:17845/.

КАК СОСТАВИТЬ КП
Слева — разделы КП, идите по ним сверху вниз (кнопка «Далее» внизу каждого раздела):
 1. Клиент — получатель, дата, город.
 2. Оборудование — подбор из каталога (фильтры по мощности, двигателю, альтернатору, исполнению), опции.
 3. Цены и валюта — валюта КП, курс ЦБ РФ (кнопка «Загрузить курс ЦБ РФ» заполняет курсы сама),
    закупка, маржа (по умолчанию 35 %) и цена продажи. Любое значение можно исправить вручную.
 4. Титульный лист — заголовок и ключевые параметры (заполняются из каталога).
 5. Условия — сроки, оплата, гарантия, доставка.
 6. Менеджер — контакты в КП.
Зелёная галочка — раздел заполнен, красная точка — в разделе есть что исправить.
Справа — итог, список незаполненного (нажмите на пункт — откроется нужный раздел) и кнопка «Сохранить КП».

ОБЩИЙ КАТАЛОГ ДЛЯ ОТДЕЛА
Впишите в settings.json путь к сетевой папке, например:
  { "dataDir": "\\\\server\\Отдел продаж\\КП" }
(в JSON обратная косая черта пишется двойной). Тогда каталог, журнал и готовые КП
будут общими для всех, у кого программа настроена на эту папку.
Не редактируйте одну и ту же позицию каталога одновременно с коллегой — сохранится последнее изменение.

ЕСЛИ НЕ ЗАПУСКАЕТСЯ
• Windows SmartScreen «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
• Антивирус может насторожиться на самодельный EXE — это ложное срабатывание; добавьте файл в исключения
  или попросите IT-службу.
• Курс ЦБ не загружается — нужен доступ в интернет к cbr.ru (прокси Windows используется автоматически);
  курсы всегда можно ввести вручную.
