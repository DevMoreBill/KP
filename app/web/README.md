# Интерфейс конструктора КП (app/web)

Обычные HTML + CSS + JavaScript, без сборщиков и фреймворков. Сервер (`app/kp_server.py`) отдаёт `index.html`
и файлы по адресам `/web/...`. Правка — в любом редакторе, результат виден после обновления страницы (F5).

## Как устроено

- **Файлы — обычные скрипты** (не ES-модули), подключаются по порядку из `index.html` и делят общее пространство
  имён: функции и константы одного файла видны в следующих. Порядок важен только для кода, который выполняется
  сразу при загрузке (константы, `S`), поэтому: `core/*` → `features/*` → `docx/build.js` → `ui/*` → `main.js`.
- **Состояние** — один объект `S` (`core/state.js`): клиент, позиции `S.items`, цены, титул, условия, менеджер.
  После изменения: `renderForm()` (перерисовать раздел и панель) и `persist()` (сохранить черновик).
- **Поля ввода** связаны с состоянием атрибутом `data-p="путь"` (например `items.0.name`, `contact.post`) —
  обработчик в `ui/events.js` сам записывает значение через `setP()`. Поле рисует `field(label, path, опции)`.
- **Кнопки** — атрибут `data-a="действие"` (+ `data-i`, `data-j`, `data-k`), обработка — в `switch` в `ui/events.js`.
- **Разделы формы** — массив `STEPS` в `ui/form.js`; каждый раздел — функция `stepXxx()` в `ui/steps/`, возвращающая HTML.
- **Сервер** — только через `api(путь, опции)` (`core/api.js`); список адресов — в корневом README.
- **Удаление** — только в «Настройках» (`features/settings.js`, сервер `app/admin.py`). Кнопок удаления в остальных
  окнах нет; сервер отклоняет DELETE без входа администратора. Сохранение товара — `CatSrv.put()`: при включённой
  модерации ответ `{pending:true}`.
- **Телефоны** — правила в `css/mobile.css`; новые окна (`dialog`) на ≤768 px автоматически открываются на весь экран.

## Частые задачи

| Задача | Где |
|---|---|
| Новое поле в разделе | `ui/steps/<раздел>.js` → `field(...)`; значение по умолчанию — `freshState()` в `core/state.js` |
| Новая кнопка | разметка с `data-a="имя"` + `case 'имя':` в `ui/events.js` |
| Проверка перед сохранением | `problems()` в `ui/sidebar.js` |
| Вёрстка документа Word | скелет шаблона `templates/<id>/skeleton.js`, настройки — `template.json`, форма редактора — `editor.json` |
| Новый вид оборудования | без кода: `app/equipment_types.json` или «Типы оборудования» в программе |
| Цвета интерфейса | переменные в начале `css/base.css` |
